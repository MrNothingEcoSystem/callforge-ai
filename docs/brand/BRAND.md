# CALLFORGE Brand Identity

Premium, ASIC-inspired identity: a forged silicon die with gold pin
traces. The mark represents a hardened, engineered core — precision
hardware discipline applied to a simulation-first voice platform.

## Assets

| Asset        | File                   | Use                                |
| ------------ | ---------------------- | ---------------------------------- |
| Primary mark | `callforge-mark.svg`   | App icon, favicon source, avatars  |
| Banner       | `callforge-banner.svg` | README header, docs, presentations |

## Palette

| Token             | Hex       | Role                                    |
| ----------------- | --------- | --------------------------------------- |
| `--cf-obsidian`   | `#0B0F16` | Deep background, chip body              |
| `--cf-graphite`   | `#1B2230` | Raised surfaces                         |
| `--cf-gold`       | `#C9A227` | Primary accent, pins, wordmark gradient |
| `--cf-gold-light` | `#F2D98C` | Highlights, signal core                 |
| `--cf-bone`       | `#F5E7C1` | Primary text on dark                    |

## Typography

- Display / wordmark: high-contrast serif (Georgia fallback), wide tracking.
- Body: system sans; never set body copy in gold.

## Rules

- The die mark must sit on obsidian/graphite or bone; never on busy imagery.
- Gold gradients are reserved for the mark and headings — not body text.
- Do not stretch, recolor, or add drop shadows to the mark.
- Branding is not a launch claim: CALLFORGE remains simulation-only until
  a separately authorized release gate passes (see `LAUNCH-GATES.md`).
